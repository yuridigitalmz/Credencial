Estrutura da Base de Dados MySQL & Script PHP

Para ligar este frontend ao seu servidor MySQL/PHP próprio, utilize a seguinte tabela SQL e o endpoint PHP correspondente para gerir os RSVPs em tempo real:

1. Tabela MySQL (schema.sql) 
CREATE TABLE rsvp_responses (
    id INT AUTO_INCREMENT PRIMARY KEY,
    guest_name VARCHAR(150) NOT NULL,
    status ENUM('Sim', 'Nao') NOT NULL,
    guests_count INT DEFAULT 0,
    notes TEXT NULL,
    pass_code VARCHAR(50) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
2. Endpoint PHP de Exemplo (api_rsvp.php) 
<?php
header('Content-Type: application/json');
$pdo = new PDO('mysql:host=localhost;dbname=lux_events;charset=utf8', 'DB_USER', 'DB_PASS');

if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $data = json_decode(file_get_contents('php://input'), true);
    $stmt = $pdo->prepare("INSERT INTO rsvp_responses (guest_name, status, guests_count, notes, pass_code) VALUES (?, ?, ?, ?, ?)");
    $stmt->execute([$data['name'], $data['status'], $data['guests'], $data['notes'], $data['passCode']]);
    echo json_encode(['success' => true, 'message' => 'RSVP Guardado no MySQL com sucesso!']);
}
?>
